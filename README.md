# massaman-board

マッサマンゲームのお題と、回答者の発言をリアルタイムで全画面表示するボードです。
司会（入力係）がキーボードで発言をタイプすると、番号付きで画面に並んでいきます。
HTML ファイル1つで動作し、サーバーやビルドは不要です。

公開ページ: https://takenory.github.io/massaman-board/

## 使い方

1. 最初の画面で参加者をエントリーします。
   - 大きな名前欄に1名入力し、Enter で確定すると、すぐに次の参加者を入力できます。登録済みの参加者は同じ画面に一覧表示します。登録完了画面や専用の一覧画面への遷移はありません。
   - 2名以上登録すると「お題の入力へ」が表示されます。2〜6名で開始でき、「1つ戻す」で最後の登録を取り消せます。
   - プロジェクターなどに映す場合は、右上の「全画面」で全画面にしておくと、そのまま本番画面まで全画面で進みます。
2. 「お題の入力へ」でお題入力へ進みます。「参加者を編集」で戻れます。お題を入力して `Enter` または「開始する」で「それでは開始します」と表示され、本番画面に切り替わります。
3. 回答者の発言をタイプすると、画面中央に巨大な文字が暗号のように解読されながら現れます（変換中の文字も表示）。
   `Enter` を押すと、その文字が一覧の位置へ飛んで判子のように着地し、砂塵が舞います。発言者は人数分を順番に自動で回ります。
4. 発言は番号付きで上から縦に並びます。1列の行数は「回答者数×2」で、埋まると右の列へ続きます。
   最新の発言は回答者の色で光って強調され、単語が増えると全体が収まるよう文字サイズが自動で小さくなります。
5. 次のお題に進むときは「新しいお題」を押します（回答があるときは、3秒以内にもう一度押すと確定）。
   人数と名前はそのまま引き継がれます。

各参加者ボックスの「脱落にする」で脱落マークが付き、以後の手番ではその人を飛ばします。「復帰させる」で取り消せます。過去の発言はそのまま残ります。
2人以上で開始して残り1人になると、勝者の名前を大きく表示します。「ボードに戻る」で閉じられます。勝者決定後は発言入力を停止し、参加者を復帰させると再開します。

同じラウンドで既出の発言を入力すると「すでに出た発言です」と表示し、記録と手番を進めません。入力は選択状態で残るので、そのまま修正できます。判定は前後の空白を除いた完全一致です。新ラウンドでは脱落・勝者・発言をリセットします。

## キー操作（本番画面）

| キー | 動作 |
| --- | --- |
| `Enter` | 発言を追加（発言者は自動で次の人へ）。日本語変換の確定の `Enter` では追加されません |
| `Tab` / `Shift+Tab` | 発言者を次／前の人に切り替え |
| 入力欄が空の状態で `Backspace` | 最後の発言を取り消し（発言者もその人に戻る） |
| `Esc` | 入力ドックを隠す／出す（表示専用モード）。隠れている間に文字を打つと自動で再表示 |

入力ドックのボタン: 発言者の切替、「1つ戻す」、「全画面」、「新しいお題」

OS の「視差効果を減らす」設定が有効な場合は、動きと砂塵の演出を行いません。

デザインは、夏祭りのデザインテーマ（ドラマ『VIVANT』の世界観）に合わせた「夜の砂漠と諜報の機密ファイル」です。番組のロゴ・題字は使用していません。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体（HTML / CSS / JavaScript を1ファイルに収録） |
| `spec.md` | 仕様書。機能・画面・動作の正となるドキュメント |
| `README.md` | このファイル |

## 開発

このリポジトリは仕様駆動で開発します。変更は次の順で進めます。

1. `spec.md` に変更内容（要件・受け入れ条件）を追記・修正する
2. `index.html` を実装する
3. `spec.md` の受け入れ条件に沿ってブラウザで確認する
4. 仕様と実装を同じコミットに含めて push する

ローカルでは `index.html` をブラウザで直接開けば動作します（`open index.html`）。
`main` ブランチに push すると GitHub Pages に反映されます。
