# massaman-board

マッサマンゲームのお題と、回答者の発言をリアルタイムで全画面表示するボードです。
HTML ファイル1つで動作し、サーバーは不要です。

公開ページ: https://takenory.github.io/massaman-board/

## 使い方

1. お題を入力して `Enter`（回答者の名前は任意で変更可）
2. 「それでは開始します」の表示後、回答者の発言をタイプして `Enter`
3. 発言は番号付きで、上から6個ずつ縦に並び、埋まると右の列へ続きます

## キー操作

| キー | 動作 |
| --- | --- |
| `Enter` | 発言を追加（発言者は自動で次の人へ） |
| `Tab` / `Shift+Tab` | 発言者を切り替え |
| 空欄で `Backspace` | 最後の発言を取り消し |
| `Esc` | 入力欄を隠す／出す（表示専用モード） |

「全画面」ボタンでフルスクリーン表示、「新しいお題」（2回押しで確定）で次のラウンドへ進みます。
